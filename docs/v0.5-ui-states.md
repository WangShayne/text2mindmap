# text2mindmap v0.5 UI 交互与切片联动状态表

本文档为 v0.5 前端提供交互状态与视觉规范，字段对齐 `docs/v0.5-api-contract.md`。

---

## 1. 切片状态表 (Slice States)
对应接口 `Slice`（`id, start, end, text, take, status: 'ok'|'failed'`）及前端状态。

**状态归属说明**：
- 服务端权威状态只有 `Slice.status: 'ok' | 'failed'` 两个值。
- `pending`、`transcribing`、`retrying` 是前端音频管线的流转状态；`active` 是导图反向选中的焦点状态。这四个都由前端状态机维护，后端不会返回。

| 状态 | 归属 | 触发时机 | 样式与视觉 | 标签/图标 | 交互行为 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **pending** (排队) | 前端 | 切片截断，待 ASR | 虚线浅灰框 `#D1D5DB`, 浅灰底 `#F9FAFB` | ⏳ `[mm:ss]` | 禁用；骨架屏“等待转写...”；不联动导图。 |
| **transcribing** (转写中) | 前端 | ASR 正在识别音频 | 浅蓝框 `#93C5FD`, 浅蓝底 `#EFF6FF` 呼吸条 | ⚡ `[mm:ss]` | 禁用；提示“正在识别语音...”；不联动导图。 |
| **done** (`status: 'ok'`) | 服务端 | ASR 成功返回文本 | 常规卡片白底灰框；hover 蓝框 `#3B82F6` | `⟦sN⟧` + `01:12` | **可点击**：点击高亮并聚焦右侧导图对应分支。 |
| **active** (导图选中) | 前端 | 导图选中关联节点 | 蓝底强描边 `#2563EB`, 浅蓝底 `#DBEAFE` | 🎯 选中标签 | 平滑滚动居中；1.5s 蓝色光晕后常驻选中底色。 |
| **failed** (`status: 'failed'`) | 服务端 | ASR 报错/静音/超时 | 红框 `#FCA5A5`, 浅红底 `#FEF2F2` | ⚠️ 警告图标 | 不联动导图；正文斜体弱化；右侧提供重试按钮。 |
| **retrying** (重试中) | 前端 | 点击重试/自动补偿 | 黄框 `#FCD34D`, 浅黄底 `#FFFBEB` | 🔄 旋转加载 | 禁用重复点击；成功转 `done`，失败恢复 `failed`。 |

## 2. 导图节点与切片三档精度联动表 (Precision Grades)
对应接口 `NodeRef`（`path, sliceIds, timeRange, take, precision: 'slice'|'section'`）。

| 精度分级 | 判定条件 | 节点标记 | 导图->逐字稿 | 逐字稿->导图 | 提示文案 (UI Copy) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **切片级精准** (`precision: 'slice'`) | 保留 `⟦sN⟧`，映射切片 | 蓝色微标 `[01:12]` / 🔗 锚点 | 左栏平滑滚动到首个切片居中；切片 1.5s 蓝色聚焦闪烁 | 导图平滑微调平移（不改缩放）；节点 1.5s 呼吸光晕 | “精准对应切片 01:12 - 01:28 (切片 #s12)” |
| **分节级范围** (`precision: 'section'`) | 丢弃 `⟦sN⟧`，降级为整节 | 浅灰标签 `~10m` 或 `[第 1 节]` | 左栏滚动至该节起始切片；顶部提示“已定位至章节区间”；**不承诺单句定位** | 导图定位高亮该节对应主分支树；提示属于本节概要 | “对应第 1 节整体要点 (00:00 - 10:00)，未精确到句” |
| **无映射** (无 NodeRef / 空) | 根主题/过渡/自建节点 | 无时间戳与链接图标 | 仅选中导图节点本身，左栏**不滚动、不高亮** | 不涉及 | “该节点为总结概述，无直接关联录音切片” |

## 3. 分段进度条各阶段与异常提示表 (Batch & Streaming Alerts)
长录音 `mode: 'transcript'`（5~10 分钟分节）及实时切片。

> 说明：表中 `isRecording` / `isGenerating` 等变量名为示意，以前端 Hook 实际导出为准。

| 阶段 / 场景 | 判定条件 | 进度条视觉形态 | 状态文案 (Status Text) | 交互阻断性与恢复策略 |
| :--- | :--- | :--- | :--- | :--- |
| **录音中** | `isRecording: true` | 红点呼吸 + 计时器 `05:23` + 音量波形 + 切片计数 | “正在录音 05:23 · 已切片 12 段” | 导图只读保护；停止录音按钮常亮。 |
| **分节提炼** | 收到切片，分节 LLM 生成 | 分段步进器（完成绿勾，当前节蓝圈 Spinner，后续灰点） | “正在提炼第 1 节要点 (00:00 - 10:00)...” | 非阻断；允许在左栏浏览已完成切片；导图只读。 |
| **合并分支** | 收到 `section_done`，全文合并 | 步进器进入合并阶段，进度条条纹动态滑动流动 | “正在融合分支节点...” | 右侧导图准备接收增量更新。 |
| **全部完成** | 收到 `done` 事件 | 进度条全亮显示绿勾，3s 后收折为轻量摘要 | “生成完毕 · 共处理 32 个切片，3 个章节” | 自动退出只读模式；恢复导图编辑权限。 |
| **单切片失败** | 单切片 `status: 'failed'` | 对应切片进度微格显示橙红点；主进度条不中断 | “切片 #s5 转写异常，已跳过并继续处理” | **非阻断**；不中断后续流程；可点击切片重试。 |
| **网络断连** | SSE 中断或超时 | 进度条变黄警示，顶部弹出吸顶 Banner | “与服务连接中断，正在尝试重连 (1/5)...” | 保护现场：保留现有逐字稿与导图；提供手动重试。 |
| **409 忙碌（增量录音）** | 增量请求返回 `409 { code: "busy", seq }` | 无变化 | 无（不提示） | **非阻断**、无弹窗、不打扰用户；前端把未确认切片静默合并到下一周期一起重发（不排队）。 |
| **409 忙碌（手动重复发起）** | 用户重复手动点击生成，返回 409 | 轻量 Toast | “当前任务正在处理中，请稍候” | 防重复提交；不置灰录音入口。 |

## 4. 增量更新动效与只读态规范表 (Incremental & Read-Only Guard)

| 功能机制 | 触发状态 | 交互/视觉设计规范 | 适配层要求 (SimpleMindMap) |
| :--- | :--- | :--- | :--- |
| **增量更新保持视口** | 接收增量推送：`changes: { added: number[][], updated: number[][] }` | **严禁重置画布或缩放比例**；保持当前平移（Pan）与缩放（Zoom）绝对不变。 | 调用 `setOutline(tree, { reset: false })`，内部触发 `mm.updateData()`，避免调用 `mm.view.fit()`。 |
| **新增节点光晕动效** | `changes.added` 中的路径（只列新增子树的**根**） | 光晕只加在新增子树的根节点上（子节点不单独加）：外围施加 **1.5 秒浅蓝呼吸光晕**：`animation: pulse-glow 1.5s ease-out; box-shadow: 0 0 0 4px rgba(59, 130, 246, 0.4)` | 适配层按 `uid`/`path` 添加 temporary class `node-pulse-highlight`，动画结束后移除。 |
| **已有节点更新提示** | `changes.updated` 中的路径（已有节点、直接子节点变多） | 施加约 1 秒淡蓝柔和边框闪烁：`border-color: #60A5FA`，0.8s 淡入淡出；仅提示内容已刷新，不造成视觉跳动。 | 适配层按 `path` 添加 temporary class `node-updated-flash`，动画结束后移除。 |
| **视口边缘溢出微调** | 新增节点超出当前可视窗口 | 仅当新增节点不可见时，触发**平滑小幅微调平移**（`dx, dy`）使新节点露出边缘，弹出小气泡：“新增要点已生成”。 | 适配层按 `mm.getTransform()` 与节点边界计算小位移平滑滚屏，不改变 `scale`。 |
| **录音与生成只读态** | `isRecording === true` 或 `isGenerating === true` | 1. 导图右上角常驻胶囊标签：`🔒 录音生成中 · 导图只读`<br>2. 禁用双击编辑、节点拖拽排序与右键删除；<br>3. **保留导航能力**：支持平移、缩放、点击节点触发逐字稿溯源。 | 设置 SimpleMindMap `readonly: true`；若用户尝试双击修改，弹出轻气泡：“录音与生成中不可编辑导图结构”。 |
